# Live Wallpaper

簡約、高效能且省電的 Android 影片動態桌布應用程式。支援本機影片與網路影片一鍵套用，提供豐富的自訂編輯與即時預覽功能。

---

## 主要功能

- **影片來源**
  - **本機相簿**：自由選取裝置內的影片檔案。
  - **網路下載**：支援貼上 Pinterest 影片連結，自動解析並下載。

- **桌布客製化設定**
  - **即時預覽**：提供手機桌面模擬視窗與時鐘，所見即所得。
  - **顯示模式**：支援「滿版裁切」、「完整顯示」與「延展填滿」。
  - **桌面遮罩**：自訂 0% ~ 60% 壓暗遮罩，確保桌面 App 圖示清晰可讀。
  - **片段剪輯**：精確裁切影片起訖時間，自訂循環區間。
  - **播放調節**：支援多段變速播放（0.5x ~ 1.5x）及獨立音效開關與音量調整。

- **智慧省電機制**
  - 關閉螢幕或切換應用程式時自動暫停，兼顧省電與流暢效能。
  - 支援桌面雙擊手勢，快速暫停或恢復影片播放。

- **歷史紀錄管理**
  - 集中管理歷史桌布，隨時快速切換或清除快取。

---

## 系統需求

- **Android 版本**：Android 8.0（API Level 26）以上
- **處理器架構**：arm64-v8a / armeabi-v7a / x86_64

---

## 使用方式

1. **選取影片**：在首頁貼上 Pinterest 影片連結或點擊卡片從相簿選擇影片。
2. **調整設定**：在編輯畫面調整顯示模式、遮罩亮度、速度或裁剪片段。
3. **套用桌布**：點擊「套用桌布設定」，依照系統提示確認即可完成。

---
